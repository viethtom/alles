# Projekte & Materialien – Thomas Vieth

Passwortgeschützte Übersicht über meine Projekte (Physik, Medienberatung & Fortbildung).

`index.html` enthält die Übersicht nur verschlüsselt (AES-256-GCM, Schlüssel per PBKDF2-SHA-256 aus dem Passwort). Die Entschlüsselung erfolgt im Browser; das Passwort steht nirgends im Code. `impressum.html` und `datenschutz.html` sind öffentlich.

Die Seite wird mit einem Build-Skript aus den Quelldateien erzeugt, die nicht in diesem Repository liegen.
